# Licensing status

The BR360 source package contains an explicit research/license matrix and states that the V2/V3 implementation reimplements general concepts independently (`code_copied=false` in the corpus reference records). However, the supplied package does not include a project-wide license grant.

This launch pack therefore does **not** silently add MIT, Apache-2.0 or another license on the author's behalf.

Before adding a project-wide license:

1. confirm ownership of the BR360 implementation and control text;
2. verify whether any retained text/data is adapted from sources with attribution/share-alike requirements;
3. retain required research/standards notices;
4. choose the intended contribution and commercial-reuse model;
5. add the selected LICENSE and update this file.

A permissive license such as Apache-2.0 can be considered if the rights review confirms that the repository is fully licensable under those terms, but that legal decision should be made by the rights holder.

This is an engineering release note, not legal advice.
