# Business Readiness 360 V3

BR360 V3 is an executable, evidence-driven readiness framework. It preserves V2 applicability/scoring behavior while adding a deterministic execution layer for every `AUTOMATED` control.

Core remains offline-capable and dependency-free. Optional adapters are discovered but not executed without explicit opt-in. Real-world evidence is never inferred from source code.

See `QUICKSTART.md`, `EVIDENCE.md`, `SCORING.md`, `RECURSIVE_FORMATION_INTEGRATION.md` and `IMPLEMENTATION_REPORT.md`.
